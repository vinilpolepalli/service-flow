# Service Flow

Independent demo built by Vinil Polepalli (vinilpolepalli.com), inspired by the problem space Bernard (YC S26) works in. Not affiliated with or endorsed by Bernard.

Operations board for a fictional appliance repair shop: synthetic repair tickets flow Booked -> Diagnosed -> Parts -> Scheduled -> Completed. Attention rules (PART DELAYED, SLA RISK, READY TO SCHEDULE) are fixed-threshold illustrations with the thresholds shown. Every ticket, customer and technician is synthetic; stats are computed from the sample data.

Static export of a Next.js app. Built with Claude Code.
